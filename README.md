# ZoomRide Trip Analysis

## Project Overview
This project analyzes ZoomRide's trip data using SQL to understand trip performance, revenue generation, customer behavior, and data quality.

## Objectives
- Analyze total trips and completed trips across cities.
- Identify monthly revenue trends and top-performing vehicle types.
- Identify customers who have never booked a trip and the top three customers by spending.
- Detect duplicate records, standardize city names, and investigate missing fares.

## Tools Used
- **MySQL:** Data querying, cleaning, aggregation, and analysis.

## Key Insights
The analysis identified Lagos as the highest-revenue city, generating 218,890 in revenue, with 93 completed trips. It also highlighted data quality issues, including inconsistent city names, duplicate records, and missing fare values.

## Recommendations
ZoomRide should consider investing in high-performing cities, monitor revenue and customer demand, and improve data quality to support accurate reporting and better business decisions.
